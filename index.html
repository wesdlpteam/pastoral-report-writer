Welcome to the Report Comment Companion

This tool helps you draft pastoral report comments faster, using your own words. It doesn't write reports on its own, you stay the author, it just handles the structuring and Wesley-style polish.

How it works:

  1. Answer a few short questions about the student, in your own words.
  2. Review the AI-drafted comment and edit however you like.
  3. Copy it into Word and add the student's name.

Student names are never entered into this tool. Nothing you type is saved or logged anywhere.

    Naming guide: which name to use

    If you intend to use a preferred name in the report, it must be written in brackets in the first instance and may then be used throughout the remainder of the report.

    Example: Thomas, Orson (Sonny).
    "Orson (Sonny) has completed a sound term's work. Sonny is a friendly and polite individual."

    The formal name Orson may be used throughout, although this may indicate a lack of familiarity with the actual student. Do not swap back and forth between using the formal name and the preferred name.

    If no preferred name is mentioned in brackets in Synergetic, the formal name MUST be used, even if you use an abbreviated version when you speak to this student.
