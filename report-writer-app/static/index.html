Welcome to the Report Comment Companion

This tool helps you draft pastoral report comments faster, using your own words. It doesn't write reports on its own, you stay the author, it just handles the structuring and Wesley-style polish.

How it works:

  1. Enter the student's name.
  2. Answer a few short questions about the student, in your own words.
  3. Review the AI-drafted comment and edit however you like, then copy it into Word.

The student's name and your notes are sent to our AI provider (OpenAI) to draft the comment; OpenAI is configured not to use this data to train its models. Your in-progress answers are kept in this browser only, until you finish or clear them.

Check an existing report

Paste a report comment you've already written. We'll check it against Wesley's grammar and style guide and show you what, if anything, should change.
